# mysql

The MySQL and MariaDB backend of AntelopeJS. It runs the database interface's queries on MySQL and MariaDB with mysql2.

## Requirements

<!-- antelopejs-docs-node:start -->

This package requires Node.js `>=22`.
<!-- antelopejs-docs-node:end -->
